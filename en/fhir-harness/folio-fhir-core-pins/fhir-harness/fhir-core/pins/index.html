    note
    HL7's publication is the authority. Each release is read from HL7's own core package at the URL the specification publishes it (https://hl7.org/fhir/<release>/hl7.fhir.<r>.core.tgz); `shasum` (sha1) and `integrity` (sha512) are of HL7's bytes, computed when the pin was written (2026-11-15). `bun run fhir-harness/scripts/fhir-core.ts index` refuses bytes that differ from either. A `mirrors` entry is a copy elsewhere, pinned by its own hashes; it is never read for the manifest or the class model, only to fill the local cache.
